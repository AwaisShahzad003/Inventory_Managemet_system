# Inventory Management System

A Streamlit-based inventory management application.

## Features
- Track inventory items
- Manage stock levels
- Generate reports

## Local Setup
1. Clone: `git clone [your-repo-url]`
2. Install: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`
